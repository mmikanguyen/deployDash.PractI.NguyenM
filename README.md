# Restaurant Database Management System

A relational database project developed for CS5200 (Database Management Systems) at Northeastern University. The project involved designing, implementing, and managing a MySQL database for restaurant operations using real-world restaurant visit data.

The system includes normalized tables for restaurants, servers, customers, visits, bills, meal types, and payment methods. Using R and SQL, the project supports data loading, database management, and business logic through stored procedures for inserting new visits and modifying server records.

**Technologies:** MySQL, R, SQL, DBI, RMySQL, SQLite

**Key Features:**
- Designed and implemented a relational database schema with primary and foreign key constraints.
- Imported and transformed restaurant data from CSV and SQLite sources.
- Developed R scripts to create, populate, test, and delete the cloud-hosted MySQL database.
- Implemented stored procedures to support restaurant operations and enforce business rules.
- Validated data integrity and database functionality through automated tests.
